# Tareas

Cuatro bloques que corren **en paralelo**, cada uno con un agente y su propia rama. **A** = servidor (esquema, endpoints, motor, puntos, Ably, pruebas). **B** = cliente en línea (transporte, pantallas de sala y juego, ranking, integración con Retos). **C** = "¿De dónde es?" (banco, lógica pura, UI local y pintor en línea). **D** = perfil (cliente, editor de avatar reutilizado, Home, precarga de la carrera, legal).

La interfaz entre los cuatro es `src/retos/online/protocolo.ts` (T0, copiado **tal cual** del plan, sección "Contrato A↔B↔C↔D") y las firmas de `src/retos/dedonde.ts`. Cada agente solo toca los archivos que el plan le asigna ("Archivos y dueños"). **Solo B edita `package.json` y `src/retos/index.ts`; solo D edita `src/main.ts`; solo A edita `api/` y `db/`.** `protocolo.ts` no se edita en las ramas. Las pruebas se corren con `npx tsx scripts/<archivo>.ts`. Sin la llave de Ably todo corre: las pruebas usan Ably, Neon y Wikidata falsos; el transporte falso y el de sondeo sustituyen a Ably en el navegador.

- **T0 → todo.** Después, A, B, C y D arrancan a la vez.
- **A:** A1, A2, A3, A4, A6, A7, A9 sin otras dependencias → A5 (necesita A1) → A8 (necesita C4 para las pruebas de ¿De dónde es?) → A10 (A2, A3, A5) → A11 (A4 a A9) → A12 (A5, A7), A13 (A1, A5) → A14.
